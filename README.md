# 境智 · 出入境业务智能辅助平台

当前版本为 **0.5.1，第五阶段：关联分析与交付**。系统支持 macOS 和 Linux，提供本机可运行的前后端、五套主题及明暗模式、响应式布局、环境与 AI 配置、人员与法规管理、期限核查、模板文书、询问笔录、事实画像和业务统计。

界面已升级为统一的 Nova 组件风格：本地组件源码、Lucide 图标、Motion 过渡、自定义弹框与下拉菜单，笔录工作室支持调整面板宽度。五套主题及明暗模式共用设计变量，运行时不访问组件网站或 CDN。详见 [界面升级说明](docs/ui-upgrade.md)。

导航页主视觉支持本地交互场景：拖动或方向键旋转、聚合/展开、复位及暂停。统计卡片和业务入口增加倾斜与光影反馈；“减少动态效果”可停止自动动效。工作台“小依”使用基于参考图片编辑的正面人物图，采用 2.5D 景深、呼吸起伏和有限视差，支持半身/全身取景；在正面图上增加短暂眨眼与轻微嘴角变化，暂停恢复静止表情，不提供任意角度旋转。其他场景由本地 Three.js 生成，不加载外部模型或贴图。详见 [3D 交互说明](docs/spatial-ui.md)。

第五阶段已增加事实画像、人工关系图谱、业务统计、迁移预检和备份恢复。详见 [第五阶段说明](docs/phase-5.md)。构建后可用 `bash scripts/serve.sh` 同源运行页面和 API。

## 本机启动

准备 Node.js **20.19+ 的 20.x 版本，或 22.12 及以上版本**（含 npm；不支持 21.x 和 22.0–22.11），以及 Python **3.11 或更高版本**。Node.js 要求与 `package.json` 的 `^20.19.0 || >=22.12.0` 一致。

在项目目录执行：

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

首次安装或升级后重新运行 `setup.sh`，再完整重启前后端。扫描、模板处理与 TXT/DOCX 导出不要求安装 Office、LibreOffice 或云端转换服务。非 MP3 音频在转写前需要服务器另行安装 **FFmpeg**，程序通过本地转换生成 MP3 副本，原音不变；没有 FFmpeg 时仍可保存原音、手工整理或上传 MP3。程序不自动安装 FFmpeg，也不包含本地语音识别模型。安装脚本需要可用的软件包源；前端运行不加载在线字体、CDN 脚本或远程图片。

启动后访问 [本地预览](http://127.0.0.1:5173)，后端健康接口为 [API 健康检查](http://127.0.0.1:8000/api/health)。前端通过 Vite 将 `/api` 请求代理到 `127.0.0.1:8000`。

8000 或 5173 端口被占用时，脚本会退出并说明原因，不结束已有进程。按 `Ctrl+C` 仅停止本次脚本启动的服务。后端默认不开启自动重载；修改后端代码或运行环境后，停止脚本再启动。

## 使用顺序

1. 在人员档案中手工录入资料，或先下载 CSV 模板、填写资料来源并预检，再确认导入。示例行是虚构内容，使用前替换。
2. 在知识库中导入法规原件，核对解析文本、来源、版本与生效日期后发布。导入不会自动认定资料具有法律效力。
3. 先使用本地检索查看条款及原件。仅在需要 AI 辅助解释时启用服务商，并把适合外发的公开法规单独标记为允许外发。
4. 发起问答前明确确认本次外发。系统不会自动加入人员档案或停留记录；问题框本身会发送给服务商，不应填写人员身份、笔录或其他非公开资料。
5. 在期限核查工作台补充延期、回执和核实来源后运行扫描，按实际资料记录核查、关闭或重新打开；每次人工处置均须填写备注。
6. 在文书中心核对模板，选择人员和停留记录起草；也可从预警详情携带关联进入。补齐所用变量后，保存并导出草稿；人工核对须填写意见并明确确认。
7. 在智能笔录中新建询问记录，选择业务场景，可关联人员快照。通过浏览器录音或上传音频，先保存原音；也可直接手工录入。转写仅发送所选一段音频，摘要仅发送当前已保存修订文字，两者各自需要明确确认。
8. 回听并修订文字，人工标注角色及需要的起止位置；核对全文后填写意见并锁定。导出默认不包含 AI 摘要，选入时会标为辅助内容，不能替代原话。

扫描版 PDF 需要先用另外部署的**本地 OCR 工具**处理；本阶段不自带 OCR。普通 DOCX 和文字 PDF 的解析结果仍需人工核对，复杂表格、页眉页脚与条款分页可能影响分段。

浏览器录音需要麦克风权限及安全上下文。本机 `localhost` / `127.0.0.1` 可用于验收；另一台手机访问普通 HTTP 局域网地址不满足麦克风要求。当前录音目标为每段 5 分钟，可分多段保存；手机锁屏和后台录音连续性、华为 nova14 / 鸿蒙 5 尚未真机验证。详情见 [第四阶段说明](docs/phase-4.md)。

人员与知识库操作见 [第二阶段历史说明](docs/phase-2.md)，预警、规则与文书操作见 [第三阶段说明](docs/phase-3.md)。

站内切换页面、关闭编辑窗或放弃录音时，未保存内容通过自定义弹框确认。为了不出现浏览器原生离开提示，刷新、关闭标签页及离开本站不会弹出拦截提示；请先保存修改和录音。文件选择、麦克风授权等浏览器或操作系统界面由其自身控制。

## 环境与数据

默认数据存放于 `backend/data/`：`settings.sqlite3` 保存服务端配置（包括 AI 模型、服务地址与 API Key），`test.sqlite3` 保存测试环境业务表和审计表。知识库原件、解析文本、预警规则与历史、补充事实、模板、文书快照，以及笔录音频、转写、修订版本和摘要均保存在当前数据库中。音频会增加数据库及备份体积。

需要指定其他数据目录时，在启动前设置绝对路径：

```bash
export NEXT_NIA_DATA_DIR="/absolute/path/to/next-nia-data"
bash scripts/dev.sh
```

`.env.example` 仅说明可用环境变量；**后端与启动脚本不会自动加载 `.env` 文件**。更换数据目录会使用另一套独立配置和数据，不搬迁原目录。

测试模式使用 SQLite，正式模式使用已配置的 PostgreSQL。正式环境保存前验证连接；**环境切换重启生效，不自动迁移、合并或复制数据库**。启动时创建本应用尚不存在的表，保留既有数据；当前没有通用数据库结构迁移工具。PostgreSQL 尚未经过真实服务集成验证。

“正式模式”表示数据库配置模式，不表示已经完成多人生产部署。数据库故障不会自动回退测试库或补入虚构业务数据。

预警自动扫描仅在后端进程运行且开关开启时执行；停机期间不扫描，重启后检查是否到期并补做当前扫描，不重放停机期间每天的结果。规则默认提前 30 天、重点关注 7 天、间隔 60 分钟；手动扫描使用当前北京时间，不能提交自选业务日期。

## AI、可选检索与密钥

服务商地址固定为硅基流动或 DeepSeek。连接测试只访问模型列表接口；问答、转写与摘要另行检查 AI 开关、对应服务商、凭据与本次确认，法规问答还检查资料外发标记。音频转写固定使用硅基流动，默认 `FunAudioLLM/SenseVoiceSmall`；摘要使用当前默认聊天服务商与模型。模型列表检查通过不代表 ASR 格式兼容、生成质量或模型结构化输出能力已经验证。

原始转写、人工修订和 AI 摘要分别保存。当前不提供流式转写、可靠的自动逐字时间戳或自动说话人识别；角色和时间位置由人工填写。片段文字、角色、音频关联、时间位置或顺序发生实质修改后，旧摘要显示过期并禁止附入当前导出。

默认检索为本地词法检索，不要求向量模型。可选的 SentenceTransformer 本地语义检索通过 `NEXT_NIA_EMBEDDING_MODEL_DIR` 配置，需另装可选依赖并提前准备完整模型目录。**默认安装没有这些重型依赖或模型，也没有完成本地语义模型运行验收；程序不会自动下载模型。** 详见 [部署说明](docs/deployment.md)。

普通配置接口不返回密钥原文；管理员配置页通过专用鉴权接口回显 API Key，可编辑或隐藏。留空保留已存密钥，清除需独立操作。`settings.sqlite3` 权限为 `0600`，API Key 和数据库密码仍是**本地明文存储**，未实现密钥加密或密钥管理服务。首次启动会迁移旧 `settings.json`，数据库提交成功后移除旧文件。备份或搬迁时需同时保留配置数据库和业务数据库。配置、数据库、虚拟环境和依赖目录均忽略提交。

## 使用已有资料工作空间

```bash
bash scripts/presentation.sh
```

兼容启动脚本继续使用 `backend/presentation-data/`，保留现有账号、业务数据及配置。`NEXT_NIA_PRESENTATION=1` 只控制独立 SQLite 工作空间首次准备资料和录音资料库入口；不再改变 AI 执行方式。PostgreSQL 不自动填充示例资料。普通 `bash scripts/dev.sh` 使用 `backend/data/`，避免误以为换启动方式会自动迁移数据。

**所有启动方式使用同一套真实 AI 适配器。** 已删除录音哈希匹配文字、预设本地问答、摘录代替 AI 摘要和定时假进度。没有密钥、服务商失败、输出被截断或来源引用不合法时，返回错误/依据不足，不能生成成功结果。现有历史文字整理资料保留，页面注明其来源；新建资料批次不再预填 AI 成功记录。

配置步骤：

1. 管理员进入“后台配置 → AI 服务”，填写硅基流动 Key，启用服务商及 AI 总开关，保存。DeepSeek 可作为文字生成服务商；语音转写仍使用硅基流动。
2. “检测模型”只验证凭证和模型列表。“实际生成测试”通过业务摘要适配器发送固定会议文字，校验 JSON 和来源；“语音转写测试”发送内置中文测试 MP3，校验非空文本及关键词。后两者产生真实调用费用，不读取业务资料，不自动保存配置。
3. 法规导入后审核发布，核对生效日期并允许该公开法规用于外部 AI；问答只发送用户问题与这些片段。不能自动将历史未获准外发的资料改为允许。
4. 智能笔录上传/录制任意有效音频，确认本次外发后转写；原音及原始转写留存本地。人工修订保存后再生成摘要、要素和来源引用；失败也保留请求状态。非 MP3 使用本机 FFmpeg 转换副本。
5. 人员、停留、预警扫描/处置、文书模板填充/审核/导出、事实画像、图谱、统计、账号权限、迁移与备份均由本地服务和活动数据库执行。文书模板填充属于确定性本地业务，不依赖语言模型编写法定措辞；人员画像可读取关联笔录中最新、未过期的真实 AI 要素，选择登记为待核验事实，保留原文快照，重复登记不新增；历史本地摘要、归档笔录和过期结果不进入候选。核实结论仍由人工登记。

测试录音 `backend/assets/healthcheck.mp3` 内容为“这是语音识别连接测试。今天下午三点召开工作会议。”，由本机中文语音工具生成，不含业务数据，运行时不依赖 macOS 语音工具。

接口参数依据：[硅基流动对话接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)、[语音转写接口](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)、[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。Qwen3 混合模型关闭思考以生成结构化 JSON；DeepSeek 显式使用非思考模式。模型是否在账号下可用由模型检查和实际测试确定。

自动测试会使用隔离数据库与协议替身；通过不等同于云端验收。2026-10-25 已用真实硅基流动接口验证 5.4 秒测试录音转写（SenseVoiceSmall）、结构化摘要（Qwen3-8B）、来源要素登记、Word 导出和本地检索引用问答。测试库已删除，真实业务资料未外发。DeepSeek（deepseek-flash）也已使用真实接口完成会议测试文字摘要、结构化要素及引用校验、本地画像登记、Word 导出和检索引用问答联调，使用临时数据库且未修改业务数据；长录音、噪声及实际业务质量仍需专门评估；真实 PostgreSQL、手机 HTTPS/麦克风、法定文书模板及可选本地向量模型仍需对应环境或材料。扫描件 OCR、自动说话人识别、电子签章和正式送达不是已实现能力。

如需恢复开场资料，先停服务，再执行 `bash scripts/presentation.sh --reset`。旧工作空间会整体移至 `backups/presentation-时间戳/`，不会删除原数据或影响 `backend/data/`。不要对正式业务工作空间执行资料重置。


### 局域网访问

当前已使用的工作空间可通过以下命令启动局域网预览（保留原账号、数据和 AI 配置）：

```bash
NEXT_NIA_HOST=0.0.0.0 bash scripts/presentation.sh
```

同一局域网设备访问 `http://服务器局域网IPv4:5173`；本机仍可访问 `http://127.0.0.1:5173`。前端代理同源 `/api`，后端 8000 端口继续只监听本机，登录与跨站请求保护保持生效。启动前先停止本项目旧服务；无需修改密钥或数据库。不设置 `NEXT_NIA_HOST` 时仍默认仅本机访问。

构建后的单端口服务也支持 `NEXT_NIA_HOST=0.0.0.0 bash scripts/serve.sh`（默认 8080）；使用当前工作空间时同时设置 `NEXT_NIA_DATA_DIR="$PWD/backend/presentation-data"`。局域网普通 HTTP 可浏览页面及上传录音，浏览器现场录音需要 HTTPS 安全上下文。
