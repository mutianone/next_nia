# 境智 · 出入境业务智能辅助平台

当前交付为**第一阶段：基础框架与环境配置**。平台仅支持 macOS 和 Linux。本阶段提供界面框架和配置管理，后续业务模块仍在规划中。

## 本阶段范围

| 能力 | 当前状态 |
| --- | --- |
| 总览工作台 | 测试环境展示明确标记的演示数据；正式环境不加载演示业务数据 |
| 多主题与明暗模式 | 五套主题、白天/黑夜模式，支持响应式布局 |
| 系统设置 | 系统名称、单位名称、运行环境、AI 服务商设置 |
| 数据库环境 | SQLite 测试环境 / PostgreSQL 正式环境配置与连接检查 |
| AI 接口配置 | 硅基流动、DeepSeek 的凭证与模型连接测试 |
| 登录 | 本阶段不提供登录页，开发预览仅监听本机环回地址 |
| 人员档案、法规知识库、问答 | 尚未开发 |
| 逾期预警、正式文书、录音转写、智能笔录、人员事实画像 | 尚未开发 |
| 手机安装包 | 尚未启动；响应式网页不等于 Android/HarmonyOS 安装包 |

AI 连接测试仅向选定服务商的模型列表接口验证凭证与所选模型，不提交业务资料，不代表已完成问答或转写能力。

## 本机启动

准备 Node.js **20.19+ 的 20.x 版本，或 22.12 及以上版本**（含 npm；不支持 21.x 和 22.0–22.11），以及 Python **3.11 或更高版本**。Node.js 要求与 `package.json` 中的 `^20.19.0 || >=22.12.0` 一致。首次安装依赖需要可用的软件包源；应用前端不使用在线字体、CDN 脚本或远程图片。

在项目目录执行：

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

启动后访问 [本地预览](http://127.0.0.1:5173)，后端健康接口为 [API 健康检查](http://127.0.0.1:8000/api/health)。前端通过 Vite 将 `/api` 请求代理到 `127.0.0.1:8000`。

脚本会检查平台、Node.js、Python 虚拟环境、依赖与端口。8000 或 5173 已被占用时会退出并说明原因，不会结束已有进程。按 `Ctrl+C` 仅停止本次脚本启动的服务。后端默认不开启自动重载；修改后端代码或运行环境后，停止脚本再启动。

启动脚本可从其他目录通过绝对路径执行，内部会自动定位项目根目录，不依赖特定用户名或安装路径。依赖更新后重新运行 `scripts/setup.sh`。

## 环境与数据

默认数据存放于 `backend/data/`：

- `settings.json`：服务端运行配置，包含已保存的 API Key 和数据库密码。
- `test.sqlite3`：测试环境数据库。

如需指定其他数据目录，在启动前设置绝对路径：

```bash
export NEXT_NIA_DATA_DIR="/absolute/path/to/next-nia-data"
bash scripts/dev.sh
```

`.env.example` 仅说明可用环境变量。**后端与启动脚本不会自动加载 `.env` 文件。** 更换数据目录相当于使用另一套独立配置和运行数据，并不会搬迁原目录。

在“系统设置”中选择测试或正式环境。正式环境需要已创建的 PostgreSQL 数据库及有效账号，保存前会校验连接，应用启动时需要创建自身审计表的权限。**环境设置保存后重启生效；切换不会自动迁移、合并或复制数据库。** PostgreSQL 启动失败时不会静默回退 SQLite，也不会加载演示业务数据。

“正式环境”目前表示数据库运行模式，不表示完整业务系统已经达到生产上线条件。完整人员、预警、知识库和笔录流程尚未开发。

## 配置和密钥

在“系统设置”中启用 AI 并配置硅基流动或 DeepSeek。服务商地址固定，API Key 由后端保存；配置读取接口只返回“是否已配置”，不返回原始密钥。留空表示保留已存密钥，清除使用独立操作。

配置文件限制为运行账号读写（权限 `0600`），**当前属于本地明文存储，没有实现密钥加密或密钥管理服务**。运行数据和密钥已加入忽略规则，不应提交版本库。备份目录也应按包含密钥的敏感数据管理。

本阶段没有身份认证和用户权限控制。默认仅供本机开发验收；不要把 Vite 开发服务器或配置接口直接开放至公网或业务内网。后续手机访问需要受控网络入口与 HTTPS，不能只把监听地址改成 `0.0.0.0` 就视为部署完成。

## 检查命令

```bash
npm run typecheck
npm run build
backend/.venv/bin/python -m pytest backend/tests
bash -n scripts/common.sh scripts/setup.sh scripts/dev.sh
```

这些命令供开发验收使用；运行结果以实际输出为准。`npm run build` 只生成前端静态资源，单独打开 `dist/index.html` 或运行 Vite preview 不等于部署完整前后端服务。
