# 分阶段交付与验收范围

当前版本为 0.3.0，第三阶段。各阶段分别开发和验证；尚未启动的模块在界面中显示规划状态。

## 第一阶段：基础框架与配置（已交付）

React + TypeScript + Vite 前端、FastAPI 后端、五套主题及明暗模式、移动布局、系统设置、SQLite 测试模式和 PostgreSQL 正式模式配置。环境修改在验证后保存，重启生效；数据库之间不自动迁移。

AI 配置包含硅基流动、DeepSeek 的服务商、密钥和模型列表连接检查。配置不回传原始密钥。无登录页面，默认仅本机环回访问。

第一阶段的演示统计已在第二阶段替换为当前数据库中的真实汇总，不继续显示虚构预警。

## 第二阶段：人员事实档案与法规知识库（已实现）

- 人员新增、编辑、筛选分页、人工核验标记、可逆归档；证件类型与归一化号码组合去重。
- 停留事实新增与编辑、日期关系校验。未知的准许停留期限保持为空，不据此推断违法。
- 人员 CSV 模板、预检、全有全无导入与筛选导出；限制大小与条数，导出防护电子表格公式执行。
- 本地 TXT、Markdown、文字 PDF、DOCX 导入，原件和解析文本保存在当前数据库；法规版本、人工审核发布、归档、生效区间与来源管理。
- 本地 BM25 与字词精确匹配融合检索，按日期筛选有效的已发布资料，提供条款、版本和来源回溯。
- 可选 AI 法规问答：只使用获准外发的公开法规检索片段，外发前明确确认，不自动接入人员记录；校验输出的引用标识。
- 工作台读取人员、停留记录和知识库统计；基础写入审计记录标识与计数，不记录人员详情或密钥。

当前默认未安装 SentenceTransformer 重型依赖或本地模型。可选本地语义检索有配置入口和降级机制，但尚未完成模型运行验收。扫描 PDF 的 OCR 不包含在本阶段，需要先通过另外部署的本地工具转成可提取文本的文件。

真实 PostgreSQL、真实云模型端到端效果、法规全量资料质量和目标手机浏览器仍需在相应环境中验证。引用标识有效不代表模型陈述获得了语义证明，也不代表法律判断正确。导入资料、问题与法规中的指令均作为数据，不作为系统指令执行。

详细范围见 [第二阶段说明](phase-2.md)。

## 第三阶段：期限预警与文书模板（当前已实现）

- 北京时间确定性日期规则、手动与后台周期扫描、真实预警统计、筛选分页、人工处置及时间线。
- 签证有效期、准许停留期限、延期批准、受理回执及实际离境分别记录。未确认材料显示事实待核查，截止日期和倒计时不强行推算。
- 无预警时也可选择人员与停留记录补充事实，人工核实时校验来源及已批准延期日期。
- 版本化纯文本模板与白名单变量、模板审核与归档、人员/停留快照、预警关联建稿、文书审核锁定、复制和归档。
- 本地 TXT/DOCX 导出，缺项拒绝导出；草稿保留待审核标识，人工核对稿仍标明未签发。模板和文书更新使用版本号冲突检测。

自动扫描仅在后端运行时执行；停机期间不扫描，重启后按到期状态补做当前扫描，不补造历史结果。提醒不代表违法认定，手动关闭和自动关闭均保留记录。

限期出境相关文书的正式名称、固定措辞、文号、救济告知和版式，仍等待业务方提供经确认的现行模板。内置且标为已审核的模板仅为内部核查工作单，不能解释为法定文书标准已确认。系统不自动作出执法决定，未实现签发、电子签章或送达。

操作与边界见 [第三阶段说明](phase-3.md)。业务模板、真实生产数据库、目标手机和正式排版仍需验收；本地自动测试不代替这些工作。

## 第四阶段：中文录音与智能笔录（未启动）

计划实现录音采集、本地音频保存、中文转写、时间位置关联、人工修订、摘要、关键要素抽取、模板匹配与导出。

原始音频、逐字转写、修订稿和 AI 摘要分别保存。说话人区分、时间戳、长音频和移动端录音，需要结合实际模型和真机验证，不能从普通聊天接口推断为已支持。

## 第五阶段：事实画像、统计与完整交付（未启动）

计划实现带来源与核验状态的人员事实汇总、业务时间线、统计报表、旧数据迁移、备份恢复及运维交付。关系展示依据记录中的事实，不自动推断违法倾向。第二阶段只提供基础事实档案和工作台汇总，不代表本阶段的完整画像、统计或迁移已完成。

正式业务上线前还需身份认证与权限、审计使用流程、HTTPS 入口、数据保留策略、恢复演练和业务验收。本机无登录验收版本不视为已具备多人生产部署能力。

## 暂未启动的扩展

- Android APK 与 HarmonyOS 应用：先完成网页，再依据目标设备实际系统确定封装、权限和分发方案。
- LoRA 领域微调、全库 GraphRAG：先使用业务题集评估检索和生成质量，再根据具体不足选择技术。
- 短信、公网通知、第三方地图和外部业务接口：不属于当前本地化范围。
