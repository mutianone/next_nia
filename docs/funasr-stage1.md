# Fun-ASR 第一阶段：识别结构与版本隔离

## 范围

保留阿里云 HTTP 异步文件识别，不增加模型或供应商。本轮不实现 SpeakerTurnBuilder、QA 状态机、跨批次声纹匹配或二次校正界面，不修改原始 Word 模板或前端布局。

## 数据与兼容

新增 `record_recognition_runs`、`record_recognition_sentences` 两张附属表。供应商原始 JSON、句子/词级数据不可通过业务编辑覆盖；当前 `record_segments` 仍为人工可编辑正文。没有元数据的历史记录继续按旧格式读取，不伪造角色或时间。

统一解析所有 transcripts/sentences，保留 channel_id、sentence_id、speaker_id、words、句词时间（毫秒）。匿名编号不再写入 Fun-ASR 文本；业务角色仍为 unknown，人工角色映射沿用现有审核入口。编号作用域是 recognition_run_id + speaker_id。原始结果引用为 run ID，完整供应商 JSON 保存在该运行记录中，不写日志或自动加入通用详情响应。

连续录音保持原音分片、录音操作及调度机制不变；每个识别批次保存逐句原始结果，分析使用句子 ID，完成后逐句投影到正文。批次内时间与会话样本区间映射同时保存，词级也保留对应映射。现有调度仅生成连续、不重叠区间；处理前检查分片序号、样本数、实际偏移，不完整批次不外发。映射器支持不连续输入区间，跨缺口句子保存多段位置，不生成虚假连续时间。

重叠窗口的原句保留在识别版本中，正文保守跳过有重叠的句子，并记录重叠来源、时间范围与 `overlap_review_required`。无句级时间时按来源窗口保守检查，不能证明新内容的部分不自动加入正文。不会自行裁剪文字或猜测切分点。

同一供应商 task_id 恢复使用稳定识别 ID；业务来源范围独立命名。相同运行重复处理不插入重复原句/正文，若同任务返回不同内容则报409，保留既有原始结果。不同任务保存为独立版本；同一音频已有正文或已应用版本时，新版本不自动加入正文，也不覆盖人工修改。

## API

- 原 `POST /api/records/{id}/audio/{audio_id}/transcribe` 兼容原请求。
- 可选 `recognition_request_id` 为客户端生成的UUID。提供新的值表示允许新提交任务；恢复该次请求必须复用相同值。省略时沿用音频缓存恢复行为。重复查询原任务不保证产生新识别。
- `GET /api/records/{id}/recognition-runs` 返回独立识别版本、句词元数据、区间映射和正文投影状态；不返回原始供应商JSON中的文件访问链接。
- 重新识别版本的比较/选择界面属于后续阶段，本轮不自动应用。
- 原音删除沿用既有授权接口，并清理相应附属识别数据。

## 迁移

迁移文件：`backend/migrations/20261115_asr_results.py`。

先停止应用/后台工作线程并备份数据库，然后在项目根目录执行：

```bash
backend/.venv/bin/python -m backend.migrations.20261115_asr_results 'sqlite:////实际路径/数据库.sqlite3'
```

迁移仅新增表及索引，可重复执行；不删除、不改写旧记录。现有启动时 `Base.metadata.create_all` 也会创建相同新表。测试只对临时数据库执行迁移，没有手工对业务数据库运行迁移。附属表纳入现有按 metadata 导出的备份流程。回滚代码前应保留两张附属表，不通过删除表丢弃识别历史。

## 修改文件

- backend/app/record_asr_results.py：标准化、原始版本、逐句来源、时间映射、幂等投影与兼容读取。
- backend/app/record_fun_asr.py：统一解析，不添加文本标签；显式请求键；缓存有效窗口缩短到23小时。
- backend/app/record_capture.py：保存逐句检查点；来源引用和样本偏移；完成后逐句写入。
- backend/app/records.py：上传识别版本隔离、附属数据读取、原音删除联动、版本查询接口。
- backend/app/records_ai.py：透传新识别请求键。
- backend/app/record_qa_review.py：现有人工映射从独立字段读取编号，按运行隔离。
- backend/app/record_selection.py：适配不含说话人文本前缀的新结构，保持未确认声音的保守行为。
- backend/migrations/20261115_asr_results.py：增量迁移。
- backend/tests/test_asr_results.py：本轮模拟验收。
- backend/tests/test_fun_asr.py、backend/tests/test_records.py：更新已废弃行为的断言，验证新行为。

## 验证结果（2026-11-15）

所有新测试使用模拟/虚构数据，不调用真实云端识别。

- 本轮相关回归：139通过（标准化、版本、连续录音、原音删除、问答审核兼容、任务及导出）。
- 新增验收覆盖：单人多句、交替发言、多轨、空speaker、空words、异常时间、跨批次、重复任务、不同识别版本、同号隔离、重叠/缺时间窗口、非连续区间映射、人工修改保护、历史读取、幂等迁移、超过正文容量的原始结果保存，以及三种Word模板导出。
- 全量后端：478通过、49失败、1错误；剩余失败/错误均出现在修改前文件基线复跑中。初次全量发现的本轮普通对象兼容回归已经修复。
- 基线复制目录未携带项目根目录CLI/静态产物，额外出现3个路径相关失败；它们不在修改后的失败集合中，不据此判断新代码通过。
- 全量前端：83通过、5失败；失败位于 DemoData.test.tsx（3）和 Presentation.test.tsx（2）。本轮未修改前端源文件。
- 生产构建通过。
- 三种既有 `test_original_word_template_filled_and_samples_removed` 回填测试在修改前后均失败；新增导出测试以已验证字段为夹具，确认渲染/导出兼容，不把它计作AI回填准确率证明。

## 限制

不能宣称全项目测试全绿。历史预警、账户、配置、演示及模板回填测试问题未在本轮扩大修复。未重跑真实云端音频，不能以模拟测试证明说话人识别或回填准确率提升。匿名编号仍需人工确认；不同批次不自动关联声音。重叠句可能包含尚未重复的尾部，整体留待核对而不猜测截断。当前正文最多500片段，超限原始识别版本完整保留，连续录音暂停正文应用。词级位置只有供应商返回时才存在。
