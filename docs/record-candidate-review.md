# 智能笔录：方案对照与本轮实现

本轮继续使用现有 React/Vite + FastAPI 系统。语音识别、语义提取调用已配置的云端接口，不安装 FunASR、Qwen 或其他本地推理服务。FFmpeg 仅用于本机音频格式转换，不属于本地模型。

## 方案对照

| 提案 | 现有基础与本轮处理 |
| --- | --- |
| 重建 Java/Vue 主系统 | 保留已实现的账户、模板、录音、版本和文书导出，避免迁移现有业务数据。 |
| 问答独立保存 | 新增 `record_qa_pairs`；仅按明确问答标记或人工角色标签配对，保留原文字符范围；追问关系只是提示。未标注的自由转写仍由云端模型分析。 |
| 规则优先、AI 辅助 | 标准问题精确匹配且没有后续不明确问答时，直接提取原回答；其余模板字段交给云端。遇到追问时保守使用上下文分析。 |
| 候选版本与审核 | 新增 `record_field_candidates` 和 `record_field_reviews`；同轮早期回答、后续候选以及跨次生成均独立保留；采用、驳回追加审核记录。 |
| 人工保护与冲突 | 人工修改及已采用字段不被后台生成覆盖；新旧文字不同提示差异，不声称已判断语义矛盾或真假。替换人工保护值需要明确操作；未处理差异拦截全文核对。 |
| 原文来源与回听 | 规则匹配保存精确字符范围；AI 改写只能保证关联段落时明确标注段落，不伪造精确引文。没有音频时间戳时从原音开头回听。 |
| 后台任务与恢复 | 沿用分组任务、检查点、失败恢复和版本冲突检测；已完成分组不重复发送。 |
| 文书与归档 | 保留原 Word 模板回填、DOCX 导出、全文核对、归档和恢复规则。生成仍为待人工审核草稿。 |
| 禁止删除原音 | 不采用此项，遵守用户此前要求：删除音频同时清除相关文字、合并结果、候选及审核数据。审计只记录操作标识和数量。 |
| 实时 ASR、双声道、断线续传 | 用户已确认暂时保留硅基流动录音后转写，本轮不新增实时服务。整文件转写不冒充流式识别。 |
| 模板配置 | 系统设置新增笔录模板管理：原 Word 模板可配置问题别名、提取说明和必填项；可新建自定义问题清单。配置采用追加版本，新任务取最新启用版本，旧任务保留快照。 |
| PDF 与版本对比 | PDF 从同一份 DOCX 通过本地 LibreOffice 转换，可下载与分页预览；历史对比展示字段前后值及两版全文。 |
| 复杂模板与审批 | 尚未实现任意 Word 文件的网页导入/版式编辑、条件显示/重复字段、部门多级审批；自定义问题清单使用通用版式，原有三个 Word 模板保持原版式。 |

## 操作方式

选择模板 → 保存录音并转写（或保存人工修订）→ 按模板生成 → “模板生成与依据”中的“候选回填与人工审核” → 查看原文/回听 → 采用或驳回 → 成文预览核对 → 全文核对并锁定 → 导出/归档。

首次生成的候选仍可自动写入草稿以节省填写时间；候选本身不等于已人工确认。采用会保护字段；驳回会撤回未人工修改的候选值，恢复生成前值，人工保护值保留。全文核对是明确的批量确认动作，会记录剩余候选最终采用或人工修订状态。

旧记录没有候选数据时继续显示旧分析及原文引用；重新生成后产生新候选。历史来源改变后不能直接采用旧候选。审核接口沿用登录、写权限、草稿状态和版本号校验。

## 接口与部署

- `POST /api/records/{id}/candidates/{candidate_id}/review`：expected_revision、decision（confirmed/rejected）、note，以及替换人工保护值时的 replace_protected。
- `GET /api/records/{id}/candidates/{candidate_id}/evidence`：生成时保存的原文范围、来源精度、可用音频及位置。
- 笔录详情新增 candidates、qa_pairs。
- 新增三张表由启动时 create_all 创建；不迁移或删除既有笔录。备份兼容升级前缺少这三张表的文件。

## 验证边界

自动化测试使用合成数据与模拟云端响应，覆盖问答字符范围、追问保留、精确匹配减少外发字段、候选版本、采用/驳回、人工保护、过期拦截、全文核对、删除清理，以及原有录音时间、分组恢复、Word 模板和备份回归。

独立临时数据库的浏览器验收通过：选择模板、保存合成转写、后台生成、查看依据、页面采用候选、DOCX 导出、全文核对和归档。未对本轮新增逻辑重新进行真实收费模型的长音频准确率测评；模型提取效果仍需用代表性录音单独评测。


## 后续补齐（2026-11-04）

- 管理员入口：系统设置 → 笔录模板。配置保存后，新建笔录使用新的快照；调整已有笔录到其他模板时，问答来源按模板版本隔离。
- 原模板字段/问题和 Word 回填位置不可随意改动；只编辑提取说明、别名、必填状态。自定义问题清单支持添加/移除问题，并使用通用 DOCX 版式。
- 全文核对前检查必填项。停用模板不会删除原有笔录，仅阻止新的选择。
- 工作室右侧“修订与操作记录 → 版本对比”，可选择任意两次已保存版本，展示字段差异与只读成文。
- “成文预览 → 导出 PDF / 分页预览”，与 DOCX 同源。转换期间正文版本变化时拒绝返回旧文件；后台仍在生成时拒绝导出。
- PDF 转换仅在本机执行，不调用模型或外部文档服务。生产服务器需安装 LibreOffice 和模板所需中文字体；可用环境变量 `CRJ_SOFFICE_BIN` 指定 soffice 可执行文件。转换限制为两个并发任务、每次60秒、最大50MiB，临时文件自动清理。
- 新增 `record_template_revisions` 追加版本表，随启动自动创建；旧备份兼容缺少新增表的情况。

新增验证：管理员/业务权限、配置版本冲突、原模板字段保护、新旧笔录快照隔离、自定义模板、必填项、停用模板、跨模板问答隔离、PDF/Word正文一致性、转换期间并发修订。实际渲染的五页合成原模板 PDF 已检查中文与单行页码；浏览器通过管理员配置→业务账号使用→版本对比→PDF预览→全文锁定流程。语音和模型准确率测试与这些流程测试分开，不将模拟云端结果称为真实模型验收。
