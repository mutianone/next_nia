# macOS / Linux 运行与部署说明

## 当前可运行方式

第一阶段采用本机开发预览：前端监听 `127.0.0.1:5173`，后端监听 `127.0.0.1:8000`。支持 macOS 和 Linux，不提供 Windows 启动脚本。

推荐从仓库根目录运行：

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

脚本使用 `backend/.venv`，不会修改系统Python包。Node.js 需为 **20.19+ 的 20.x 版本，或 22.12 及以上版本**，与 `package.json` 的 `^20.19.0 || >=22.12.0` 一致；不支持 21.x 和 22.0–22.11。首次安装通过npm/pip获取依赖；不会自动下载安装Node.js、Python或PostgreSQL。请先由运行环境提供这些基础程序。

需要分别启动时，在两个终端的仓库根目录运行：

```bash
# 终端一：API
backend/.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

```bash
# 终端二：前端
npm run dev -- --port 5173 --strictPort
```

前端 `/api` 代理依赖后端8000端口。`/api/health` 用于查看当前生效环境与待重启状态；页面保存设置成功不代表运行环境已经切换。

## PostgreSQL 模式

准备可连接的PostgreSQL服务，并事先创建空数据库及应用账号。在系统设置中录入主机、端口、数据库名、用户名和密码，先测试连接，再选择正式模式并保存。数据库连接测试只执行连通性检查，不创建业务数据。

应用启动需要在配置的数据库内创建自身审计表的权限，具体授权范围由数据库管理员按实际部署管理。当前版本不提供数据库集群、高可用、主从复制或自动备份服务。

切换到正式模式后完整重启后端。SQLite数据留在原处，PostgreSQL数据也保持独立；切换不自动迁移。正式模式不显示测试演示业务记录，基础业务模块仍按路线图开发。

如果保存了正式配置后数据库不可用，启动会失败并输出错误，不会静默改用SQLite。先恢复数据库连通性再启动；需要回退配置时，停止服务并备份 `settings.json` 后，由维护人员修改配置中的环境模式为 `test`，保留原文件权限并重新启动。不要删除整个数据目录来处理连接故障。

## 数据目录与备份

默认数据目录为 `backend/data`。可在启动前设置系统环境变量 `NEXT_NIA_DATA_DIR` 为绝对路径；后端不自动读取 `.env` 文件，也不通过环境变量替换已保存的API密钥和数据库连接配置。

`settings.json` 含明文密钥及数据库密码，权限为 `0600`。只有运行账号应能访问运行数据目录。文件权限限制不是加密。请使用独立运行账号，并将备份按包含密钥的数据管理。

测试环境可在停止服务后备份整个数据目录，避免复制正在写入的SQLite文件。PostgreSQL使用数据库自带备份工具独立备份；仅复制项目目录不会备份PostgreSQL数据。当前未提供自动备份和恢复向导，正式业务上线前须安排恢复演练。

## 内网与离线准备

应用运行时不需要外部字体、图标CDN、远程图片、统计或地图接口。主动进行AI连接测试时会访问所选服务商接口；后续AI生成与转写也需要配置允许的服务商网络出口。完全物理隔离且无模型出口时，不能调用云端硅基流动或DeepSeek。

离线部署前需要在与目标系统、CPU架构、Python版本匹配的准备环境中收集依赖：npm包缓存或前端构建产物、Python wheel包、PostgreSQL安装包以及未来可能使用的本地模型权重。尤其不要直接将macOS虚拟环境复制给Linux。当前 `setup.sh` 按普通软件源安装，**尚未提供或验收完整离线安装包**。

生产静态部署需要先执行 `npm run build`，再由本地Web服务器托管 `dist/` 并把同源 `/api/` 转发到FastAPI。Vite开发服务器和Vite preview均不应作为正式业务服务。

## 移动访问与后续正式部署

当前响应式布局可在浏览器移动视口验收，环回地址不能由另一台手机直接访问。真实手机访问需要后续配置受控网络入口、HTTPS证书信任、访问控制和设备测试。浏览器录音还依赖安全上下文和麦克风授权。

本阶段尚无登录和权限体系，不提供直接开放公网或内网的生产启动脚本，也不附带未经集成验收的全栈Compose、反向代理或系统服务配置。后续正式部署阶段再交付HTTPS、身份接入、进程守护、备份恢复、监控与离线发行包，并明确实际验证过的系统版本。
