# macOS / Linux 运行与部署说明

## 当前运行方式

0.4.0（第四阶段）采用本机验收方式：前端监听 `127.0.0.1:5173`，后端监听 `127.0.0.1:8000`。支持 macOS 和 Linux，不提供 Windows 启动脚本。当前没有登录、身份认证和权限体系。

从仓库根目录运行：

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

`setup.sh` 使用 `backend/.venv`，不修改系统 Python 包。Node.js 需符合 `^20.19.0 || >=22.12.0`，Python 需为 3.11 或更高版本。首次安装通过 npm/pip 获取依赖，不自动安装 Node.js、Python、PostgreSQL 或本地模型。升级后重新执行 `setup.sh`，随后完整重启服务。

需要分别启动时，在两个终端的仓库根目录运行：

```bash
# 终端一：API
backend/.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

```bash
# 终端二：前端
npm run dev -- --port 5173 --strictPort
```

前端 `/api` 代理使用后端 8000 端口，并保留同源请求信息。`/api/health` 显示版本、阶段、当前生效环境与待重启状态。设置保存成功不表示运行环境已经切换。

当前按单个后端进程运行。不要在未验证并发配置和文件更新协调前增加多个 Uvicorn worker。

## 数据库与第四阶段升级

测试模式使用 `backend/data/test.sqlite3`，正式模式使用配置的 PostgreSQL。所有业务请求使用启动时确定的数据库连接；配置变更只有在完整重启后启用。

在已有人员、知识库、预警及文书表之外，第四阶段增加 `record_sessions`、`record_audio`、`record_segments`、`record_versions`、`record_transcription_attempts`、`record_analyses`，分别保存笔录、音频、当前修订片段、版本历史、转写请求和分析结果。启动使用 SQLAlchemy `create_all` 创建不存在的表，保留已有设置和业务数据；**没有引入通用数据库结构迁移工具**，不会自动改变已有表的列结构。升级前备份；若开发期间已创建不兼容的同名表，需单独迁移，不要通过删除数据库完成升级。

启动仅初始化一份内部核查工作单模板，不插入演示人员、停留、预警或文书实例。已有同标识或同名同版本模板不会被覆盖。内置模板 `internal / approved` 不代表法定文书经过业务审定。

准备 PostgreSQL 时，先创建数据库及应用账号，再在系统设置中填写主机、端口、数据库名、用户名和密码。连接测试只执行 `SELECT 1`，不建表；保存正式模式时也会验证连接。应用正式启动需要创建本应用表和后续读写的权限。

**PostgreSQL 模式尚未经过真实 PostgreSQL 服务的集成验证。** 测试中使用替身验证环境切换、失败行为和隔离逻辑，不代表已完成生产数据库验收。当前没有数据库集群、高可用、主从复制和自动备份服务。

SQLite 与 PostgreSQL 数据保持独立；切换不迁移、不合并、不复制业务数据。两个模式下的工作台均读取当前数据库，不自动注入演示人员或虚构预警。

正式配置下数据库不可用时，启动失败并输出错误，不静默改用 SQLite。优先恢复数据库连通性；确需回退时，停止服务并备份 `settings.json` 后，由维护人员把保存的环境模式改为 `test`，保留文件权限并重新启动。不要删除数据目录来解决连接故障。

## 数据目录与备份

默认数据目录为 `backend/data/`。如需更换，在启动前设置：

```bash
export NEXT_NIA_DATA_DIR="/absolute/path/to/next-nia-data"
bash scripts/dev.sh
```

后端和脚本不自动读取 `.env`。环境变量不会覆盖已保存的 API 密钥和 PostgreSQL 连接配置；更换数据目录会选择另一套配置与测试数据库。

`settings.json` 包含明文 API Key 和数据库密码，权限为 `0600`；文件权限限制不是加密。知识库原件及笔录原音以二进制内容保存在当前数据库；条款、人员、停留、补充事实、预警规则/历史、模板、文书快照/历史、转写、修订版本、AI 摘要和审计也在同一数据库中，未单独写到上传目录。

单个音频上限 20 MiB，每份笔录最多 30 段音频、合计 500 MiB。容量上限是单份笔录限制，系统尚未提供全库磁盘配额、音频清理策略或自动保留期。原音和多次修订/分析会增加数据库、临时空间和备份体积，应按实际资料量准备磁盘。

测试环境应停止服务后备份整个数据目录，避免复制正在写入的 SQLite 文件。PostgreSQL 应使用数据库备份工具备份业务库，并另行备份 `settings.json`；仅复制项目文件不能备份 PostgreSQL 中的人员或法规原件。备份含个人资料和密钥，应按运行数据管理。

当前未提供自动备份、恢复向导和恢复演练结果。

## 预警任务与本地文书运行

预警调度随 FastAPI 生命周期启动和停止，只扫描当前活动数据库。默认开启，提前 30 天、重点关注 7 天、每 60 分钟扫描；后台约每 30 秒检查是否到期。计划时间不是秒级执行保证，规则和上次扫描时间保存在业务数据库中。

服务停机时没有任务运行；重启后对到期任务补做一次当前扫描，不重放停机期间每个历史日期。更改规则不等于立即完成扫描。关闭自动扫描不影响手动操作；手动扫描 API 不接受外部日期，使用当前北京时间。

请保证主机时间及 `Asia/Shanghai` 时区数据库可用。界面可查看上次/下次计划与失败提示；数据不可用时不切换其他数据库、不伪造完成结果。列表读取最近扫描结果，补充事实后可手动扫描并刷新。

本地文书模板只做白名单变量替换，TXT/DOCX 由 Python 标准库生成，无 Office、LibreOffice、云端转换和额外 AI 依赖。DOCX 使用通用 A4 文档结构、正文和页眉保留草稿/未签发标识；当前不提供 PDF、电子签章、正式签发、送达或法定制式版式保证。目标办公软件的字体和分页须单独核对。

第四阶段笔录 TXT/DOCX 同样在服务器本地生成。导出本身不要求服务器安装中文字体或办公软件；查看、打印和渲染验收应使用具备中文字体的文档阅读器。文件中的标识不因使用其他编辑器而构成正式签发。

模板和文书采用 `expected_revision` 检查及数据库锁/事务，旧版本写入返回冲突；这些防护不等于已完成多人生产压测。文书内保留模板及人员/停留快照，修改原档案不自动改写历史文书，复制旧稿也保留旧快照。备份必须包含数据库，单独保存导出的文件不能恢复版本与审计。

## 本地音频处理与浏览器录音

录音保存和回听不要求 FFmpeg。云端转写以 MP3 为提交格式：MP3 原件可直接提交；WAV、WebM、Ogg、M4A、FLAC 在发出请求前由服务器上的 FFmpeg 转成单声道、16 kHz、48 kbit/s MP3 副本，原件保持不变。转换不调用外部接口，也不会自动安装或下载 FFmpeg。

部署前准备支持相应解码器及 `libmp3lame` 编码器的本地 FFmpeg。默认从服务进程的 `PATH` 查找 `ffmpeg`；也可在启动前指定绝对路径：

```bash
export NEXT_NIA_FFMPEG_BIN="/absolute/path/to/ffmpeg"
bash scripts/dev.sh
```

FFmpeg 不可用时，非 MP3 转写会在外发前返回明确错误；本地保存、手工笔录和 MP3 转写入口仍可用。检查到可执行文件不代表其所有编码器均可工作。转换最多运行 90 秒，输出限 20 MiB；达到一小时时长上限或接近输出大小上限会拒绝该次结果，不把截断音频发送到云端。转换使用临时目录且完成后清理，主机仍需有可写临时空间。程序不需要 ffprobe。

需要转码的音频发生解码错误或包含多条音轨时，拒绝转换且不发送残缺内容；多音轨文件须先在本地选择所需音轨，导出为单音轨音频后再上传。

文件保存时不做完整音频解码；时长来自浏览器或人工声明并标为 `declared`，未知时为 `unknown`。直接提交 MP3 不会在服务器重新测量时长；小于 20 MiB 不代表一定短于一小时。需自行核对长 MP3 并拆分，服务商也可能拒绝不符合其限制的文件。

浏览器录音需要麦克风权限及安全上下文。本机 `localhost` / `127.0.0.1` 可以用于开发验收；手机访问 `http://局域网IP` 不满足麦克风安全上下文要求，实际设备访问需受信任的 HTTPS。客户端按运行时能力选择录制 MIME，不通过修改扩展名伪装格式；停止后合并该次全部数据块，再上传完整音频。

每次录音以 5 分钟为停止目标，可多段保存；后台计时器、锁屏、系统暂停及资源限制会影响停止时间和录音连续性。时长声明不是逐字对齐依据，也不证明录音完整。浏览器或播放器不能解码某种文件时，可下载原件在兼容的本地软件中核对。华为 nova14 / 鸿蒙 5 的麦克风、回听和下载行为尚未真机验收。

## 默认检索与可选本地模型

默认安装仅使用本地 BM25 和字词精确匹配，不安装 SentenceTransformer 或下载模型。该方式支持离线法规检索，界面会显示实际检索模式。

可选本地语义检索要求提前准备兼容的完整 SentenceTransformer 模型目录，并在适配目标操作系统和 CPU/GPU 的环境安装：

```bash
backend/.venv/bin/python -m pip install -r backend/requirements-semantic.txt
export NEXT_NIA_EMBEDDING_MODEL_DIR="/absolute/path/to/local-embedding-model"
bash scripts/dev.sh
```

本阶段没有默认安装这些重型依赖或模型，也没有完成真实本地模型的运行、性能或质量验收。以上是可选配置路径，不代表任何具体模型已经适配。模型权重应放在项目代码仓库之外。

加载时限制为本地文件并关闭远程自定义代码，不自动联网下载。目录无效、依赖缺失、加载或推理失败时，接口会说明实际状态并使用本地词法检索。改变模型路径后重启后端；不要把“已填写路径”当作模型已经加载。

当前语义向量按请求计算，没有持久化向量数据库或大规模索引建设。大批量资料的容量、并发和响应时间需要后续实测。

## 文件解析边界

默认解析 TXT、Markdown、DOCX 正文与可提取文字的 PDF，单文件不超过 10 MiB。原件、解析文本和条款关联留在本地数据库。加密、损坏、无可提取文字或超过解析限制的文件会返回错误。

扫描 PDF 需要先通过另行部署的本地 OCR 工具转换，当前不包含 OCR 引擎。不要接入未批准的在线转换服务来代替本地处理。转换后的条款、页码和表格仍需人工核对。

## AI 网络出口与确认

连接测试访问选定服务商的固定模型列表接口。法规问答只有在 AI 与默认服务商启用、凭据已配置、检索到已发布且有效并获准外发的资料、用户明确确认本次外发后，才调用固定聊天接口。

- 硅基流动：`https://api.siliconflow.cn/v1`。
- DeepSeek：`https://api.deepseek.com`。

应用不跟随服务商 HTTP 重定向，也不自动使用进程的环境代理设置。需要受控网关出口时，应由部署网络保障这些固定目标的可达性；不要把服务商地址改成任意第三方 URL。

问答发送本次问题及获准外发的法规片段，不自动加入人员档案、停留记录或数据库配置。`allow_external` 是人工设置的许可标记，不是自动公开性或隐私检测。问题文本也会发送，请勿输入非公开个人资料。无云端出口时，保留本地检索和资料管理，AI 问答不可用。

笔录转写固定向 `https://api.siliconflow.cn/v1/audio/transcriptions` 提交所选音频，默认模型 `FunAudioLLM/SenseVoiceSmall`。笔录摘要向所选服务商的固定聊天接口提交当前已保存的修订片段；不附带原音、人员档案或其他笔录，但文字本身可能含有个人资料，外发前须人工确认本次范围。AI 总开关、对应服务商开关、凭据及本次明确确认均为必要条件。此许可不会自动开启其他笔录或其他音频的外发。

当前没有真实凭据，未验证真实服务商问答、转写、摘要、账单用量或模型效果。模型列表连接测试也不检查录音可识别性。JSON 和来源标识校验不能证明摘要忠实、说话人正确或法律结论正确。程序不使用浏览器厂商的 `SpeechRecognition` 在线服务，没有额外语音服务网络出口；无云端出口时仍可保存、回听、手工修订和本地导出。

服务重启时会将当前数据库中中断的转写/分析请求标为失败，不自动补发。重试需人工再次确认，且可能形成新一次服务商调用；网络失败或本地中断不保证远端未接收或未计费。当前没有跨进程持久任务队列或自动补偿重试。

## 内网、离线与移动部署

本地业务与默认检索不需要外部字体、CDN、地图、统计、OCR 或业务数据接口。离线准备环境需收集与目标系统、CPU 架构和 Python 版本匹配的 npm 构建材料、Python wheel、PostgreSQL 安装包、需要时使用的 FFmpeg 可执行文件，以及自行选择的可选模型文件。不要把 macOS 虚拟环境直接复制到 Linux。

`setup.sh` 仍按常规软件源安装，**尚未提供或验收完整离线发行包**。

后续生产静态部署需先 `npm run build`，由本地 Web 服务器托管 `dist/`，并将同源 `/api/` 转发到 FastAPI。Vite 开发服务器和 preview 不作为正式业务服务。当前不附带未经集成验证的全栈 Compose、反向代理或系统服务配置。

环回地址不能由另一台手机访问；目前移动适配指浏览器响应式界面，目标手机尚未真机验收。实际访问需配置受控网络、HTTPS 信任、访问控制和设备测试。浏览器录音模块已提供，APK/HarmonyOS 封装仍未启动；当前代码不自动开放局域网监听或配置证书。
