# 3D 主视觉与交互

主视觉从第四阶段引入；第五阶段继续压低高度，增加无人操作时的自动旋转、悬浮与轨道动效。业务新增见 [第五阶段说明](phase-5.md)，AI 外发规则不变。

## 页面与操作

11 个导航页均提供主视觉：工作台“小依”人物、法规助手连接网络、知识库书页、人员档案卡片、期限雷达、笔录麦克风与声波、文书、事实关联示意、统计柱、主题色卡及配置控制板。画像和统计已接入当前数据库；顶部三维图形仍为视觉示意，不代表真实人员关联、扫描结果、业务数量或录音状态。

- 鼠标拖动场景旋转；触屏水平拖动旋转，纵向手势保留页面滚动。
- 场景获得焦点后，方向键调整视角，Home 或复位按钮恢复初始角度。
- 聚合/展开调整场景元素间距；暂停仅停止自动运动，仍可手动查看。
- 外观页“减少动态效果”和操作系统同名设置停止自动浮动、场景转动、声波及卡片倾斜。手动旋转保留。
- 统计卡片、业务入口和主题卡片支持轻微倾斜及跟随指针的光影。表格、文字编辑区和业务表单保持平稳。

## 本地与性能

Three.js 0.186.1 和模型代码由本地构建打包；不依赖外部模型、贴图、字体、地图、CDN 或第三方展示接口。原有 AI 接口约束不变。

渲染模块动态加载，当前路由只创建一个场景。装饰场景限制为 30 fps，像素比上限 1.5（人物场景为 1.75），不使用昂贵的后期处理。离开可见区域或标签页进入后台时停止绘制，切换页面时取消动画帧、移除观察器/事件并释放几何体、材质和 WebGL 上下文。暂停或减少动效时按用户操作、尺寸及主题变化重绘。

初次访问需要加载约 139 kB gzip 的本地 3D 模块（数值随构建变化），后续路由复用模块缓存。设备不支持 WebGL2、加载失败或上下文丢失时显示静态视觉，业务控件继续可用。无自动请求新权限或外部模型下载。

## 验证方式

`npm test` 覆盖既有自定义弹框/路由保护及新增的 3D 故障回退、键盘交互、暂停、展开、减少动效、主题更新和卸载清理。`npm run build` 包含 TypeScript 检查。

浏览器检查各导航页场景、手动旋转与暂停、主题及窄屏排版；使用独立预览端口避免改变日常预览的外观偏好。窄屏模拟不等于华为或鸿蒙真机验收。本次不向业务数据库写入演示记录。

## 工作台“小依”人物

总览工作台按用户提供的“小依.png”制作本地 Three.js 立体人物，替换原有城市模型。保留蓝色警服、黑色短发、领带、肩章、胸牌、口袋、腰带和皮鞋。人物由可旋转的网格、局部材质及本地 Canvas 徽章纹理组成；这是参考图片的风格化重建，未显示的背面、侧面由程序补全，并非由原图精确扫描获得。

默认半身取景，也可切换全身；拖动或方向键旋转，复位恢复半身初始角度。人物有呼吸、轻微重心变化、转头及眨眼动作；暂停和减少动态效果时显示静止姿态。主题仅调整底座光环，不改变肤色或警服颜色。

用户提供的原始 PNG 保存在 `public/characters/xiaoyi-reference.png`，只在加载或 WebGL 不可用时作为静态回退显示。交互模型不使用图片平面代替立体人物，不上传图片、不调用外部生成服务。
