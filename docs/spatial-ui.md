# 3D 主视觉与交互

主视觉从第四阶段引入；第五阶段继续压低高度，增加无人操作时的自动旋转、悬浮与轨道动效。业务新增见 [第五阶段说明](phase-5.md)，AI 外发规则不变。

## 页面与操作

11 个导航页均提供主视觉：工作台“小依”人物、法规助手连接网络、知识库书页、人员档案卡片、期限雷达、笔录麦克风与声波、文书、事实关联示意、统计柱、主题色卡及配置控制板。画像和统计已接入当前数据库；顶部三维图形仍为视觉示意，不代表真实人员关联、扫描结果、业务数量或录音状态。

- 工作台拖动产生有限视差；其他场景鼠标拖动旋转，触屏水平拖动旋转，纵向手势保留页面滚动。
- 场景获得焦点后，方向键调整视角，Home 或复位按钮恢复初始角度。
- 聚合/展开调整场景元素间距；暂停仅停止自动运动，仍可手动查看。
- 外观页“减少动态效果”和操作系统同名设置停止自动浮动、场景转动、声波及卡片倾斜。手动旋转保留。
- 统计卡片、业务入口和主题卡片支持轻微倾斜及跟随指针的光影。表格、文字编辑区和业务表单保持平稳。

## 本地与性能

Three.js 0.186.1 和模型代码由本地构建打包；不依赖外部模型、贴图、字体、地图、CDN 或第三方展示接口。原有 AI 接口约束不变。

渲染模块动态加载，当前路由只创建一个场景。工作台使用本地原图和 CSS 图层，不创建 WebGL 上下文。装饰场景限制为 30 fps，像素比上限 1.5，不使用昂贵的后期处理。离开可见区域或标签页进入后台时停止绘制，切换页面时取消动画帧、移除观察器/事件并释放几何体、材质和 WebGL 上下文。暂停或减少动效时按用户操作、尺寸及主题变化重绘。

初次访问需要加载约 139 kB gzip 的本地 3D 模块（数值随构建变化），后续路由复用模块缓存。其他三维场景在设备不支持 WebGL2、加载失败或上下文丢失时显示静态视觉，业务控件继续可用。无自动请求新权限或外部模型下载。

## 验证方式

`npm test` 覆盖既有自定义弹框/路由保护及新增的 3D 故障回退、键盘交互、暂停、展开、减少动效、主题更新和卸载清理。`npm run build` 包含 TypeScript 检查。

浏览器检查各导航页场景、手动旋转与暂停、主题及窄屏排版；使用独立预览端口避免改变日常预览的外观偏好。窄屏模拟不等于华为或鸿蒙真机验收。本次不向业务数据库写入演示记录。

## 工作台“小依”人物

根据用户确认，以原图保真优先，撤下程序生成的人物网格。`public/characters/xiaoyi-reference.png` 是用户原图的完整副本，保留原始文件和静止表情；动画时在面部局部 Canvas 图层压合眼睑、轻抬嘴角，增加眨眼与笑意，不整体重塑或调色人物。该展示是 2.5D，并非可任意旋转的完整三维人物。

默认半身取景，也可切换全身。人物上下约 ±9px、左右约 ±4.5px 起伏，自动眨眼约每 4.8 秒一次，笑意缓慢变化；后景光晕、椭圆轨道和地面层以不同幅度移动，形成景深。拖动和方向键只产生有限视差，不展示原图中不存在的侧面或背面。复位恢复半身和中心位置，暂停及减少动态效果时停止自动运动、隐藏表情图层并恢复原图，保留手动视差。工作台移除人物标题和可视交互提示，保留按钮与读屏操作说明。

全身和半身都使用同一张图片；主题只改变周围装饰色，不改变人物肤色或警服颜色。移动端保留纵向页面滚动，不依赖 WebGL，不上传图片、不调用外部生成服务。不可见、后台及卸载时停止动画并清理资源。
