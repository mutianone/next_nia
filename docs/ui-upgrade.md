# 界面升级与自定义弹框

本次在第四阶段功能基础上更新前端，不启动第五阶段业务开发，不迁移数据库。

## 组件与视觉

| 用途 | 实现 |
| --- | --- |
| 基础组件 | shadcn/ui 官方 radix-nova 源码，保存在 `src/components/ui/`，原许可见 `THIRD_PARTY_NOTICES.md` |
| 交互底座 | Radix Dialog、AlertDialog、Select、Switch、Tabs |
| 图标 | 继续统一使用 Lucide |
| 动画 | Motion 轻量页面/设置过渡；弹框 CSS 动画；尊重系统及站内减少动效设置 |

设置页增加配置状态概览、分类导航、统一表单及服务商卡片。笔录库和工作室更新信息层级、标签页、侧栏与阅读布局。其他业务页统一按钮、输入控件、下拉菜单和所有业务弹框。依赖随本地构建打包，不加载在线字体、图标或组件资源。

当前没有需要自由拖放排序的业务流程，因此没有引入 dnd-kit；分栏调整由专用面板组件实现。

## 弹框行为

- 编辑、查看、搜索、主题及业务确认使用同一套自定义弹框；不调用 `window.alert`、`window.confirm` 或 `window.prompt`。
- 归档、恢复、清空会话、移除文字片段、丢弃录音和放弃编辑使用明确的动作名称。确认前不执行相应业务操作。
- 取消与 Escape 不执行操作；默认焦点落在取消按钮。单按钮校验提示除外。
- 嵌套确认取消后保留原编辑窗、未保存内容及焦点；同时只处理一个确认请求，后续请求按取消处理。
- 站内导航和 hash 变化发现未保存内容时先确认。取消保留当前页面和 URL；多个编辑区域各自登记修改状态。
- 输入框的原生 HTML 约束仍然生效，浏览器校验气泡被替换成应用提示，关闭后返回需要填写的字段。
- 所有原生 `select` 菜单替换为可键盘操作的本地下拉组件，模型候选不再使用浏览器 datalist。

## 浏览器边界

浏览器不允许网页定制刷新或关闭页面时的原生离开提示。按“不使用系统弹框”的要求，本次移除 `beforeunload`，因此刷新、关闭标签页、关闭浏览器及离开本站不会出现确认框。**请先保存修改或录音**；没有宣称刷新后自动恢复未保存内容。

麦克风权限、文件选择、下载权限和原生日期输入辅助面板属于浏览器或操作系统控件，网页无法重绘系统权限界面。业务确认及编辑弹框均使用应用组件。当前手机验收是窄屏网页布局检查，不等于鸿蒙设备真机或安装包验收。

## 验收

运行 `npm test`、`npm run typecheck` 和 `npm run build`。前端测试覆盖确认与取消、Escape、并发请求、嵌套编辑保留及焦点恢复、约束校验提示、自定义空选项和未保存内容的站内导航/hash 保护。

浏览器验收使用独立测试后端与合成资料，检查主题切换、明暗模式、下拉菜单、笔录修订保存、分栏键盘调整和移动布局。实际预览使用原有数据目录；本次不向其中注入演示记录，不进行真实模型调用。构建结果不依赖测试服务。

## 2026-10-22：业务页面布局与信息层级调整

- 页面标题采用业务名称，删除重复口号、装饰性英文与阶段页脚；导航底部改为功能说明入口。
- 总览保留自动旋转的 3D 场景，主文案改为实际待核查数量和扫描时间，提供核查与笔录整理入口。统计页直接呈现筛选和报表，大屏展示保留三维场景。
- 人员、法规、文书、笔录、画像、问答、设置和主题页面直接呈现业务内容。标题旁的“三维视图”使用现有自定义弹窗，按需初始化场景、关闭即释放资源；保留拖动、键盘、暂停及减少动态效果偏好。
- 文书改为台账行，标题、关联人员、模板版本、状态、更新时间对齐展示。移动端改为纵向信息行；筛选无结果时可一键清除筛选。
- 法规改为左侧状态目录与右侧资料/条款检索，目录数量使用本地接口数据；手机端目录压缩为四项筛选。原文阅读与审核流程保留。
- 笔录库按两列整理记录，减少卡片嵌套；人员、文书、笔录与预警的统计简化为分隔式摘要，设置移除重复概览。
- 卡片倾斜只用于总览入口和主题选择。业务表格、事实和笔录保持稳定阅读平面，页面切换改为短淡入。
- 仅调整前端，不改变数据库、业务规则、AI 调用和文书签发边界。新增交互回归覆盖可选三维视图关闭焦点、法规目录切换、文书筛选后打开正确记录。
