# 第四阶段：录音与询问笔录工作室

本阶段为 0.4.0，面向 macOS / Linux 上的本机验收。网页提供原音保存、人工修订、按需云端转写与摘要、本地成文和人工核对。当前没有登录及用户权限，不自动开放手机网络访问，也不制作 APK 或 HarmonyOS 安装包。

## 已实现的工作流程

1. 新建询问笔录，填写标题、业务场景、地点和询问人员；可关联现有人员档案。关联人员信息在创建时留存快照，后续档案修改不会自动改写该份笔录。
2. 在“原始音频”中录音，或上传已有音频。停止录音后先试听，再保存到本地数据库。也可直接在“人工修订”中录入文字，无需先调用 AI。
3. 需要转写时选择一个已保存音频，查看服务商、模型和本次发送范围，明确确认后开始。成功结果保留为只读原始转写，并追加至人工修订区；不会用再次转写覆盖已有人工修订。
4. 回听原音，逐段修订文字、人工标注询问人/被询问人/翻译人员等角色；必要时填写对应音频内的起止位置。保存后留存版本，原始转写不随人工修改而变化。
5. 需要辅助整理时，先保存修订，再确认把当前修订文字发给默认聊天服务商。摘要、关键要素及待核实事项单独保存；要素引用可回到对应片段，旧分析保留当时输入快照。
6. 查看场景模板生成的成文预览，核对原音及全文，填写核对意见并明确确认后锁定。导出 TXT / DOCX 时保留草稿或未签发标识；AI 辅助内容默认不附入，需另行选择。

场景包括来华求学、婚姻家庭、居留事由核查、出入境案件询问和其他业务询问。模板根据人工选择的场景使用，不是由 AI 自动判定案件性质；整理模板未经业务方确认为法定笔录制式。

## 四类内容分别留存

| 内容 | 保存与修改方式 |
| --- | --- |
| 原始音频 | 完整原件保存在当前数据库，记录格式、字节数和 SHA-256，可回听及下载；本地转码不替换原件 |
| 原始转写 | 保留每次请求状态、服务商、模型和成功文本；只读，不冒充已人工核对的逐字记录 |
| 人工修订 | 文字、音频关联、角色及手工时间范围分别保存；保存时留存修订版本 |
| AI 辅助分析 | 摘要、要素和待核实事项单独保存，并保留分析时的输入片段快照；不写回或覆盖笔录原文 |

片段文字、角色、音频关联、时间位置或顺序发生实质修改后，原来的摘要显示过期，禁止附入当前导出。角色和手工时间参与本地失效判断，但不发送给摘要模型。引用标识校验只确认模型使用了本次提供的片段 ID，不能证明其归纳准确。AI 摘要不代替原音及逐字核对，不用于自动作出法律结论、违法倾向、可信度或敏感身份判断。

## 本地能力与外发范围

| 操作 | 是否需要云端 | 本次发送范围 |
| --- | --- | --- |
| 录音、上传、保存、回听、手工修订、核对和导出 | 否 | 无 |
| 非 MP3 转 MP3 | 否；需服务器安装 FFmpeg | 无，使用本地临时副本 |
| 音频转写 | 是，固定硅基流动 | 所选一个音频；非 MP3 发送本地转换后的副本，不发送其他音频或关联人员档案 |
| 摘要及要素整理 | 是，当前默认聊天服务商 | 当前已保存的修订片段和片段标识，不附原音、人员档案或其他笔录 |

转写与摘要各自要求 AI 总开关、对应服务商开关、API Key 和本次明确确认。摘要使用硅基流动或 DeepSeek 的聊天模型；音频转写固定使用硅基流动的专用 ASR 模型，默认 `FunAudioLLM/SenseVoiceSmall`。开启聊天服务不代表已允许所有录音外发。

修订文字本身可能包含个人资料，系统不会自动识别并清除全部个人信息；确认范围须包含这段文字本身。请求失败不会生成模拟结果或删除原音。服务商错误采用脱敏提示，原始凭据、原始 SQL 或远端完整错误响应不会显示在界面。

## 文件、容量与时长边界

| 项目 | 当前限制 |
| --- | --- |
| 单段音频 | 最多 20 MiB |
| 每份笔录音频 | 最多 30 段，合计最多 500 MiB |
| 浏览器单次录音 | 以 5 分钟为停止目标，可保存后继续录下一段 |
| 人工修订片段 | 最多 500 段，每段最多 20,000 字，合计最多 100,000 字 |
| 单次 AI 摘要输入 | 当前保存文字合计最多 30,000 字；超限拒绝，不静默截断 |
| 本地转码 | 最多运行 90 秒，输出小于 20 MiB，并拒绝达到一小时的结果 |

系统接受 WAV、MP3、WebM、Ogg、M4A 和 FLAC，实际限制与转写条件由“能力配置”接口返回。保存阶段进行大小、格式标识及归属检查，不代表完整解码或声音质量验证。音频时长来自浏览器或人工声明，标为 `declared`；未填写时为 `unknown`，不是服务器检测出的准确时长。保存时声明范围不超过 24 小时，超过一小时的声明值不能发起云端转写。

MP3 可直接提交转写；其他支持的格式需先由本地 FFmpeg 转成单声道 16 kHz、48 kbit/s MP3。缺少 FFmpeg、转换失败、超时或触及输出限制时，原件仍保留且不外发转换失败的内容。程序不自动安装 FFmpeg，部署路径和临时空间要求见 [部署说明](deployment.md)。

需要转码的音频发生解码错误或包含多条音轨时，拒绝转换且不发送残缺内容；多音轨文件须先在本地选择所需音轨，导出为单音轨音频后再上传。

直接提交的 MP3 不重新测量时长，小文件也可能很长；超过服务商时长限制的音频需事先分段。程序没有通过修改文件后缀来转换格式，也没有提供云端转换服务。

## 角色、时间位置与浏览器能力

当前转写返回普通文本，不提供可靠自动分句时间戳、逐字对齐或自动说话人识别。新转写片段的角色默认为待标注，时间为空；时间和角色只能由人工核对后填写。起止位置需同时填写且结束大于开始，并关联本笔录中的音频，不能伪装成模型测量结果。

浏览器录音需要安全上下文和麦克风权限。本机 `localhost` / `127.0.0.1` 可用于验收，另一台手机访问普通 HTTP 局域网地址不满足要求，应使用可信 HTTPS。录制格式由浏览器运行时能力决定，保存实际 MIME；不把某一种格式支持情况推广到所有浏览器。[MDN：getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[MDN：录制格式检测](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static)。

录制时的数据块不是独立音频文件：停止后会把本次全部块按顺序合并，再保存完整录音。浏览器 `timeslice` 不是精确定时器，锁屏、后台和系统暂停可能延迟数据块或影响采集连续性；5 分钟目标及界面计时不能证明录音完整或精准时长。[W3C：MediaStream Recording](https://www.w3.org/TR/mediastream-recording/)、[MDN：dataavailable](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/dataavailable_event)。

系统不调用浏览器厂商的 `SpeechRecognition` 转写接口。华为 nova14 / 鸿蒙 5 尚未真机验证，不能据桌面浏览器验收承诺其录音、回听、后台运行和下载兼容性。

## 审核、导出与数据保留

整理中内容可继续编辑；人工核对需要非空正文、核对意见和明确确认，核对后正文锁定。归档保留原件、文字、版本及结果，不是删除；归档期间停止正文导出，但仍可回听及查看历史。恢复只能回到归档前状态，原先已核对的稿件恢复后仍锁定，不能借归档解除审核。当前不提供删除原音、删除笔录或历史回滚。版本号 `expected_revision` 防止旧页面覆盖新内容；遇到冲突应重新读取并核对后保存。

详情页可只读查看保存时的成文快照，不覆盖当前稿。AI 请求开始后如另一操作更新了笔录，其返回结果会留在请求历史，但不会自动追加当前正文或作为当前摘要；重新打开后核对具体提示。一次失败的请求不会阻止后续人工整理，重试需要再次明确确认。

服务意外停止后，启动时把遗留的处理中请求标为失败，不自动重发音频或文字。中断前服务商可能已经收到请求，因此人工重试可能产生新一次调用；本地失败记录不能证明服务商未执行或未计费。

TXT / DOCX 在本地生成，草稿带“草稿·待人工审核，不得作为正式文书使用”，人工核对稿仍带“人工核对稿·未签发”。DOCX 页眉重复保留标识。摘要附件标为 AI 辅助内容；已过期分析不能附入当前导出。当前无真实签名、盖章、正式签发或送达功能。

导出不要求服务器安装 Word、LibreOffice 或中文字体；查看、打印和排版验收需要具备中文字体的办公软件。单独保存导出的文档不能恢复原音、修订历史及分析请求；备份应包括活动数据库和独立服务配置。SQLite / PostgreSQL 切换重启生效，笔录数据不会跨环境自动复制或合并。

## 已核实协议与尚未完成的验收

截至 2026-10-21，硅基流动公开 ASR 文档为 `POST /v1/audio/transcriptions`，使用 multipart `file` 和 `model`，成功示例仅含 `text`；官方限制是文件不超过 50 MB、时长不超过一小时。文档没有给出完整输入格式清单、自动时间戳或说话人响应契约，本系统不据此承诺这些能力。[硅基流动官方音频转写 API](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)。

摘要使用聊天接口 JSON 输出并在本地校验字段和片段引用。JSON 模式不保证事实正确或符合业务规则，异常、空结果或不符合本地结构的响应不能直接应用。[DeepSeek 官方 JSON Output](https://api-docs.deepseek.com/guides/json_mode/)、[聊天补全 API](https://api-docs.deepseek.com/api/create-chat-completion/)。

**当前未配置真实在线服务凭据，尚未完成真实云端转写、中文及口音识别效果、模型可用性、摘要质量、网络时延和费用验收。** 模拟接口测试只验证请求协议、边界及失败处理，不等于真实模型验收。本机已使用合成 WAV 验证 FFmpeg 转换，这也不等于云端识别效果验证。

本阶段没有本地 ASR 模型、实时流式转写、自动角色区分、自动逐字对齐、后台可靠长时录音、正式法定笔录版式、身份认证或生产恢复演练。后续范围见 [路线图](roadmap.md)。
